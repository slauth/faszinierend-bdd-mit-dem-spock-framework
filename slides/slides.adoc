== Mocking

=== JUnit

[source,java]
----
@Test
void someTest() {
    when(repository.findById(42))
        .thenReturn(Optional.of(customer));

    service.placeOrder(42, order);

    verify(mailer, times(1))
        .sendConfirmation(any(Order.class));
}
----

=== Spock

[source,groovy]
----
void "some test"() {
    given:
        repository.findById(42) >> Optional.of(customer)

    when:
        service.placeOrder(42, order)

    then:
        1 * mailer.sendConfirmation(_ as Order)
}
----

[.notes]
--
* Mocking ist in Spock eingebaut – keine zusätzliche Bibliothek
* Stubbing (`>>`) gehört ins `given:`, erwartete Interaktionen (`1 *`) ins `then:` – dort, wo man sie liest
* Mockito trennt dieselbe Aussage in `when(...)` vorher und `verify(...)` nachher
* Beispiel ist illustrativ, nicht Teil des Demo-Projekts
--

== Testnamen

=== JUnit

----
calculatesDiscount(LocalDate, BigDecimal, BigDecimal)[2]
----

=== Spock

----
member since 2026-10-06, order of 100.00 € gets 5.00 € discount
----

[.notes]
--
* Platzhalter `#memberSince`, `#total`, `#expected` im Feature-Namen werden pro Datenzeile ersetzt
* Im Report steht in Worten, welcher Fall fehlschlägt – nicht nur ein Index

== Fehlermeldungen

=== JUnit

----
org.opentest4j.AssertionFailedError: expected: <0> but was: <1>
----

=== Spock

----
Condition not satisfied:

calculator.discountFor(customer, order) == expected
|          |           |         |      |  |
|          0.00        |         |      |  5.00
|                      |         |      false
|                      |         Order[total=100.00]
|                      Customer[memberSince=2026-10-05]
<de.slauth.spock.discount.DiscountCalculator@6401d0a0>
----

[.notes]
--
* Power Assertions: ein einfaches `==` zeigt jeden Zwischenwert
* Kein Debugger, kein Hamcrest/AssertJ-DSL nötig

== Drei Dinge zum Mitnehmen

[%step]
. *Lesbar:* Given-When-Then als echte Struktur – Specs, die das Business versteht und die den Output deiner KI-Agenten prüfen
. *Datengetrieben:* `where:`-Tabellen statt `@MethodSource`
. *Aussagekräftig:* Power Assertions erklären jeden Fehlschlag

[.notes]
--
* Und der Einstieg kostet fast nichts – einfach ausprobieren 🖖
